  • Infrastructure migration: Led a full production migration from Hostinger to Hetzner with no service loss — DNS cutover via Cloudflare (proxied/direct split), block-storage volumes, and Traefik reverse proxy across dev/sandbox/prod.
  • DevOps & security: Self-hosted and hardened n8n on Docker/Ubuntu; closed the Docker-bypasses-UFW gap with network-level Hetzner Cloud Firewall rules, and managed TLS and multi-environment deploy routing.

  • Data engineering: Designed multi-tenant Supabase/Postgres schemas with per-client isolation, upsert/conflict strategies, and dedup views; integrated Google Sheets as an operational DB and client-facing output layer.
  • Client delivery: Shipped a forked, customised deployment for Banijay (international media group) with a per-client customisation log, and architected an air-gapped / on-prem spec for a security-sensitive client (Prime) using fully local models (Gemma, Whisper Large-v3) with zero external API calls.
