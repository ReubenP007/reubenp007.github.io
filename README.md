# jobsearch

Public CV / portfolio site for Reuben Potgieter — plain static HTML/CSS/JS,
served via GitHub Pages. **Everything here is public.**

## Develop
No build step. Open `index.html` directly, or serve locally:

    python3 -m http.server 8000   # then visit http://localhost:8000

## Private data
Job-search working notes (applications, cover letters, recruiter info, salary
research) do **not** live here — they're in a separate local-only repo. See
[`CLAUDE.md`](./CLAUDE.md) for the public/private rule and the publish workflow.
